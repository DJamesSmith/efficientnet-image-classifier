Dataset taken from:
1. https://www.kaggle.com/datasets/bhavikjikadara/dog-and-cat-classification-dataset
2. https://www.kaggle.com/datasets/samuelcortinhas/cats-and-dogs-image-classification


Install the required libraries from the environment
1. pipreqs . --force
2. Copy paste the dataset folders for Cat and Dog for the environment
3. Run these commands in order:
    - python main.py train
    - python main.py evaluate
    - python main.py predict path/to/image.jpg
        E.g.:
        python main.py predict test_prediction/Dogs/dog5.jpeg
